Third-party software in Tessera
===============================

Tessera, and every game built with it, includes the libraries below. Their licences follow in full.

  bgfx                 Rendering
  bx                   Base library used by bgfx
  bimg                 Image library used by bgfx
  SDL 3                Windows, input and gamepads
  Jolt Physics         Physics
  JoltC                C interface to Jolt Physics
  ENet                 Network transport
  miniaudio            Audio
  Opus                 Voice chat codec
  Dear ImGui           Editor and in-game debug interface
  cimgui               C interface to Dear ImGui
  ImGuizmo             Editor gizmos
  ImGuiColorTextEdit   Editor code view
  cgltf                glTF model loading
  stb                  Image and font loading
  KEMAR HRTF data      Headphone 3D audio

KEMAR HRTF measurements
------------------------------------------------------------------------------

The head-related impulse responses used for headphone 3D audio were measured on a KEMAR dummy head
microphone at the MIT Media Lab. Copyright 1994 MIT Media Laboratory. Provided free with no restrictions
on use, provided the authors are cited:

  Gardner, W. G., and Martin, K. D. (1995). HRTF measurements of a KEMAR.
  Journal of the Acoustical Society of America, 97(6), 3907-3908.
