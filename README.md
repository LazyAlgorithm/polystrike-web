# Ringfall for the web

Play: **https://lazyalgorithm.github.io/ringfall-web/**

This repository holds only the built game that GitHub Pages serves: the game as WebAssembly (`Ringfall.wasm`,
`Ringfall.js`), its asset pack (`game.tpak`) and the page that runs them. It is made by the Tessera engine's web build
(`tools/build_player.py --platform web`, or File > Build... > For: Web in the editor) from the Ringfall project.
Replace these files with a newer build to update the game.

## Playing with friends

Host a match from Play: the lobby shows a room code and a Copy Join Link button (Share Join Link on a phone). Friends
open the link, or type the code under Join Game. Nobody needs to forward a port or run a server.

Phones and tablets get on-screen controls. On an iPhone, Share > Add to Home Screen runs it full screen.
